# The DroneCrowd Dataset
The DroneCrowd Dataset is a large-scale video based dataset for crowd counting, crowd localization and crowd tracking on drone-captured scenes. It includes 112 video clips with 33,600 frames with a resolution of 1920x1080 pixels. Notably,
we annotate 20,800 people trajectories with 4.8 million heads and several video-level attributes. The dataset is collected by the AISKYEYE team at Lab of Machine Learning and Data Mining , Tianjin University, China. 

## Data Format

1. The dataset consists of train set (82 sequences) and test set (30 sequences). Each line in ```train.txt``` and ```test.txt``` is the index of the sequence. 
 
2. The sequences are converted into consecutive frames in the train set, val set and test set, which is recorded as ```img{seqID:%03d}{frID:%03d}.jpg``` images. For example, ```img001001.jpg``` denotes the ```001```-th frame in the ```001```-th sequence. Note that the val set is sampled from the test set.

3. The original annotation is saved in the ```.xml``` format. For convenience, we can generate the corresponding ```.mat``` format ground-truth by the `xml2mat.m` function. In each line, the points order is ```frame, id, xmin, ymin, xmax, ymax```. Moreover, the ```GT_img*.mat``` annotation in the ground-truth folder is consistent with the Shanghaitech dataset. The points order is ```x, y, id```, generated by the `saveGT.m` function.
 
4. The ground-truth density and localization maps are generated by `make_data_density.py` and `make_data_localization.py` respectively for network training. 

## License

This dataset is only for academic and non-commercial uses. We strictly comply with local laws and regulations in China when using unmanned aircraft/drones, and avoid restricted areas to capture videos. Since the scales of objects are extremely small, no identity information such as faces and vehicle plates could be retrieved. If you find yourself or your personal belongings in the dataset, please contact us, and we will immediately remove the corresponding frames.
